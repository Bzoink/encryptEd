# Lua 5.4.9

Unmodified source headers and C files from https://www.lua.org/ftp/lua-5.4.9.tar.gz.

Archive SHA-256: `2335b6c582a52654f94612bf10d2f4672805d05329aa6568b1d8cd9e5c6fb8e6`.

Only the VM, auxiliary library, base, string, table, math, and UTF-8 libraries
are linked. The application selects the exposed functions explicitly.
The upstream MIT license is reproduced in `src/lua.h`.
